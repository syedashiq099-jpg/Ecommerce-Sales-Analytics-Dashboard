# Ecommerce-Sales-Analytics-Dashboard

An interactive Power BI dashboard built to analyze sales performance, 
profitability, and customer behavior for an e-commerce business. The 
dashboard provides state-wise sales breakdowns, category and sub-category 
performance, payment mode trends, and month-over-month profit analysis to 
support data-driven business decisions.

[Dashboard Preview] https://github.com/syedashiq099-jpg/Ecommerce-Sales-Analytics-Dashboard/blob/main/Ecommerce-Dashboard%20Screenshot.png
## Tools Used
Power BI, DAX, Data Modeling
